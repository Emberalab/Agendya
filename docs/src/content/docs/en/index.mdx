## What's inside

<CardGrid>
  <Card title="Backend" icon="seti:nestjs">
    NestJS 11, modular. Auth (JWT + Google OAuth), professionals, services,
    schedules, availability, bookings, uploads. Prisma 7 on PostgreSQL, Zod
    validation, `@nestjs/schedule` cron jobs for reminders and expiration.
  </Card>
  <Card title="Frontend" icon="seti:react">
    React 19 + Vite + TypeScript, React Router 7 with route-level code
    splitting, TanStack Query for server state, Zustand for auth/theme,
    React Hook Form + Zod, Tailwind v4, Moon Design System.
  </Card>
  <Card title="Shared contracts" icon="seti:typescript">
    `@agendya/types` holds the Zod schemas for auth, professional, service,
    schedule and booking payloads — consumed by both apps so the wire format
    can't drift.
  </Card>
  <Card title="Quality gates" icon="approve-check">
    Jest unit + e2e (API), Vitest + Testing Library + MSW (web), Playwright
    end-to-end. Lint, typecheck, migrate, test and build all run in CI on
    every push and PR to `main`.
  </Card>
</CardGrid>

:::note[Source of truth]
Every page here is derived from the actual repository — the Prisma schema,
NestJS controllers and services, React routes and hooks, `package.json`

genuinely ambiguous it is called out with a `TODO` aside rather than guessed.
:::
