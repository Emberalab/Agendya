## Qué contiene

<CardGrid>
  <Card title="Backend" icon="seti:nestjs">
    NestJS 11, modular. Autenticación (JWT + Google OAuth), profesionales,
    servicios, horarios, disponibilidad, reservas, subidas de imágenes.
    Prisma 7 sobre PostgreSQL, validación con Zod, tareas cron de
    `@nestjs/schedule` para recordatorios y expiración.
  </Card>
  <Card title="Frontend" icon="seti:react">
    React 19 + Vite + TypeScript, React Router 7 con división de código por
    ruta, TanStack Query para el estado del servidor, Zustand para
    autenticación/tema, React Hook Form + Zod, Tailwind v4, Moon Design System.
  </Card>
  <Card title="Contratos compartidos" icon="seti:typescript">
    `@agendya/types` contiene los esquemas Zod de los payloads de autenticación,
    profesional, servicio, horario y reserva — consumidos por ambas apps para
    que el formato de transmisión no pueda divergir.
  </Card>
  <Card title="Controles de calidad" icon="approve-check">
    Jest unitario + e2e (API), Vitest + Testing Library + MSW (web), Playwright
    end-to-end. Lint, typecheck, migraciones, pruebas y build se ejecutan en CI
    en cada push y PR a `main`.
  </Card>
</CardGrid>

:::note[Fuente de la verdad]
Cada página aquí se deriva del repositorio real — el esquema de Prisma, los
controladores y servicios de NestJS, las rutas y hooks de React, los scripts de
`package.json`, las suites de pruebas y el workflow de CI. Donde el código dejó
algo genuinamente ambiguo se señala con un aviso `TODO` en lugar de suponerlo.
:::
